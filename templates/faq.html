AI influenced Steam
game recommendations

Providing a valid link to a Steam profile allows this application to communicate with the Steam Web API and OpenAI API, furthermore allowing the latter to generate AI based game recommendations based on various stats from the User's profile.

All API keys must be accessed through a .env file within this source directory, to ensure the security of the usage of personal API keys. Steam Web API is accessed as a wrapper through a third party Steam Python library.

Data collected is only from the Steam profile, including inventory, user stats, and game library stats. Additional information provided by the User through this application may be used for more accurate suggestions from the OpenAI API.
